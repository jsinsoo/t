037. 여러 위치에 사각형

다음 「여러 위치에 사각형」 코드에서 출력 위치 구분의 관점으로 판단할 때 옳은 설명 3개를 고르시오.
import turtle

t = turtle.Turtle()

def square(x, y, size):
    t.penup()
    t.goto(x, y)
    t.pendown()

    for _ in range(4):
        t.forward(size)
        t.left(90)

square(-150, 0, 80)
square(0, 0, 80)
square(150, 0, 80)

turtle.done()
